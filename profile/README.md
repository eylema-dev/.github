# Eylema

A Rust-first agentic AI web platform for continuous development and operations. **Current stage: design contracts and repository tooling.**

[Core project](https://github.com/eylema-dev/eylema) · [English documentation](https://github.com/eylema-dev/eylema-docs-en) · [Türkçe belgeler](https://github.com/eylema-dev/eylema-docs-tr) · [Developer guide](https://github.com/eylema-dev/devguide)

[Repository map](https://github.com/eylema-dev/devguide/blob/main/docs/en/repository-map.md) · [Examples](https://github.com/eylema-dev/eylema-examples) · [Evaluations](https://github.com/eylema-dev/eylema-evals) · [Model metadata](https://github.com/eylema-dev/eylema-models) · [Training recipes](https://github.com/eylema-dev/eylema-training)

The first planned application is a deterministic task console. GPU, model, training and autonomous-development support require their own executed acceptance evidence. English is canonical; Turkish is the second documentation language.
