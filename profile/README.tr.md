# Eylema

Sürekli geliştirme ve işletim için Rust öncelikli ajan yapay zekâ web platformu. **Mevcut aşama: tasarım sözleşmeleri ve depo araçları.**

[Çekirdek proje](https://github.com/eylema-dev/eylema) · [English documentation](https://github.com/eylema-dev/eylema-docs-en) · [Türkçe belgeler](https://github.com/eylema-dev/eylema-docs-tr) · [Geliştirici rehberi](https://github.com/eylema-dev/devguide)

[Depo haritası](https://github.com/eylema-dev/devguide/blob/main/docs/tr/repository-map.md) · [Örnekler](https://github.com/eylema-dev/eylema-examples) · [Değerlendirmeler](https://github.com/eylema-dev/eylema-evals) · [Model üstverisi](https://github.com/eylema-dev/eylema-models) · [Eğitim tarifleri](https://github.com/eylema-dev/eylema-training)

İlk planlanan uygulama deterministik görev konsoludur. GPU, model, eğitim ve otonom geliştirme desteği kendi yürütülmüş kabul kanıtlarını gerektirir. İngilizce kanonik, Türkçe ikinci belge dilidir.
